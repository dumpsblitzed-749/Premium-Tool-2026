Yes, OmniPatch is a standalone Windows tool that does not contain tool or require internet access to function. It modifies local application files only.

### Which operating systems are supported?

OmniPatch is designed exclusively for Windows 10 and Windows 11 desktop systems.

### How often are updates provided for OmniPatch?

Updates are released within 72 hours whenever a supported AI application receives a version update that might affect the patching process.

### Will this work with the web versions of the AI apps?

No, OmniPatch is designed for installed desktop applications like the official ChatGPT desktop app, JetBrains IDEs, and Cursor editor.

### Do I need to disable my anticomponent software?

Some security software may flag patching tools as potentially unwanted. You may need to create an exception for OmniPatch to run correctly.

### Can I use OmniPatch on multiple computers?

Yes, OmniPatch is a portable tool that can be copied and used on any Windows machine without installation requirements.

### What should I do if an activation fails?

Ensure you are running omnipatch.exe as administrator. Check the application's version is supported and restart both OmniPatch and the target application.

### Does OmniPatch collect any personal data?

No, OmniPatch operates entirely offline and does not transmit any user data, system information, or usage statistics.
